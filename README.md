# Neural Noodle  

**An RL Snake Game**

## Overview

**neural-noodle** is an AI-driven Snake game project built with two core components:
1. **`src/noodle`**: A basic implementation of the Snake game.
2. **`src/neural`**: Reinforcement Learning (RL) training code that uses the Snake game environment to develop an intelligent agent capable of mastering Snake.

## Experiments

The project includes several experiments, each designed to achieve specific objectives in training the Snake agent.

### Experiment Goals

- [`01 Avoid Collision`](./experiments/01_avoid_collision): Teach the snake to survive by avoiding collisions with itself and the walls.
- [`02 Apple Hunting`](./experiments/02_apple_hunting): Encourage the snake to actively seek and collect apples.

For a detailed breakdown of all experiments, see the [Experiments README](./experiments/README.md).
