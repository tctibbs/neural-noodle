# Experiment 01: Avoid Collision

The goal of this experiment is to train the snake to develop basic survival instincts by avoiding collisions with itself and the walls. This foundational behavior is essential for further complex tasks such as seeking apples or optimizing movement.

## Experiment Description

In this experiment, the snake is trained in a small grid environment to maximize survival time. The reward function is designed to encourage the snake to stay alive while penalizing it for collisions. This setup aims to evaluate the snake’s ability to learn and generalize basic survival strategies.
